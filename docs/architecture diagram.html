蒙阴·玉皇山梅花鹿智慧养殖系统架构 V2

一期技术基线｜模块化单体 · 统一事实源 · 边缘离线自治 · 本地安全控制 · AI人工闭环

核心架构决策

  • • 一期采用模块化单体，不以微服务数量衡量先进性
  • • 生产、经营、质量共用统一事实源，投影均可重建
  • • 关键交易以数据库事务提交为准，消息与页面不作成功依据
  • • Outbox 支撑至少一次分发，业务幂等消除重复影响

安全与降级边界

  • • 本地控制器独立运行，硬件联锁、急停与人工接管优先
  • • AI 只形成建议或工单，不直接获得执行器控制权限
  • • 质量放行、解冻和正式出库禁止离线最终批准
  • • 公众服务、运维网络、视频网络与现场控制网络隔离

弱网与可接管设计

  • • 边缘持久化队列按实际速率验证建议不少于 72 小时
  • • 现场记录区分本机保存、中心接收和业务确认三种状态
  • • 视频优先本地留存，关键事件片段按策略上传
  • • 数据、附件、字典、配置和未结事项均可完整导出接管

一期扩展原则

  • • 穿戴、视频 AI 和独立时序库均在场测或容量达阈值后扩展
  • • 专用图库只是事实库的可重建投影，不成为第二事实源
  • • 第三方存证属于可选适配，失败不得阻断核心交易
  • • 无法证明增量价值时保留低成本台账与规则基线
